# 回程换了顺序，哪些项仍然抵消？

先把纸转个方向，再把纸翻过来。把两个动作交换次序，结果未必相同。现在想象一串动作 $1,2,3$，然后把每个动作反做一次。按 $3,2,1$ 反做，总能从中间逐个抵消；按 $1,2,3$ 或 $2,1,3$ 反做，却不一定回到原状。能不能只看回程次序，就算出结果里的一个数？

## 三个转动平面

在三维空间取三个互相垂直的单位方向 $e_1,e_2,e_3$。用乘积 $e_i e_j$ 记录带方向的平面。在本文三角形例子的符号约定下，$e_i^2=-1$，不同方向交换位置时变号。令 $B_1=e_1e_2$, $B_2=e_1e_3$, $B_3=e_2e_3$。每个 $B_i$ 的平方都是 $-1$，不同的 $B_i$ 交换时也变号，但 $B_1B_2B_3=-1$！例如 $B_1B_2=B_3$，所以乘积就是 $B_3^2$。这种平面元素叫**双向量**；容纳实数、方向及其乘积的代数叫 **Clifford 代数**。

把一个转动写成 $U_i=c_i+s_iB_i$，其中 $c_i=\cos(\theta_i/2)$、$s_i=\sin(\theta_i/2)$。其反做对应 $\widetilde U_i=c_i-s_iB_i$，两者相乘得 $c_i^2+s_i^2=1$。我们不求整个乘积，只取它的普通实数部分（**标量部分**），记为 $t$。例如 $t(2+3B_1)=2$。

Jenzer 的定理 5.5 有一个额外条件：从这组双向量里任选非空子集，依编号乘起来，标量部分都必须为零。他在注 5.5 问能否删去这个“星条件”。上面的三个平面就不满足它；单程 $U_1U_2U_3$ 的标量部分是 $c_1c_2c_3-s_1s_2s_3$，不只是三个余弦的乘积。

## 给每一对编号记一个符号

设 $I=\{1,\dots,k\}$，$\tau$ 按位置列出回程编号，$\iota(\tau,S)$ 是所选编号中因回程而反转先后次序的对数。令 $w_i=s_i^2$。把每个编号想成独立投一次偏心硬币：以概率 $w_i$ 选入 $S$，否则不选。所选编号中，每一对**先后仍与去程相同**的编号给一个负号。最终答案就是这个符号的平均值。

::: {.theorem #loop-formula mathesis="collected:jen2610-permuted-rotor-loops:5:s1" lean="D5/S3/QuadraticForms/JenzerPermutedRotorLoop.result" title="任意回程次序的子集公式"}
设 $V$ 是有限维实向量空间，带任意符号的非退化二次型 $q$。在 $\mathrm{Cl}(V,q)$ 中，对任意 $k\ge1$、满足 $B_i^2=-1$ 且两两反交换的双向量、任意实角度及任意回程排列 $\tau$，往返积 $\Theta_k(\tau)=U_1\cdots U_k\widetilde U_{\tau(1)}\cdots\widetilde U_{\tau(k)}$ 满足
$$
t(\Theta_k(\tau))=\sum_{S\subseteq I}(-1)^{|S|(|S|+3)/2+\iota(\tau,S)}\prod_{i\in S}w_i\prod_{i\notin S}(1-w_i).
$$
不需要星条件。
:::

由于 $|S|(|S|+3)/2$ 与 $\binom{|S|}{2}$ 同奇偶，扣掉反序对之后，正好剩下相对次序不变的对。比如回程 $2,1,3$ 里，只有 $\{1,3\}$ 和 $\{2,3\}$ 计数。在三角形例子中取三个 $w_i$ 都为 $1/2$：编号 3 没选中时符号为正；选中时，编号 1、2 给出的四个符号为 $+,-,-,+$。总平均是 $1/2$。若改成逆序 $3,2,1$，一对也不计，平均值为 $1$；若只留下一个计数的编号对 $i,j$，则答案是 $1-2w_iw_j$。

## 为什么三角形里的额外项不见了？

去程选出一组 $S$，回程选出另一组 $T$。两组相同时，每个双向量都能找到配对；回程的负号、重新排序的负号和平方的负号合在一起，就是公式里的符号。

不同的两组先消去重复编号，只剩恰好出现一次的编号。标量部分满足 $t(xy)=t(yx)$，所以用可逆的 $B_j$ 共轭不会改变标量部分。共轭固定 $B_j$，并翻转其余双向量。若剩下非空偶数个编号，挑一个里面的 $j$；若剩下奇数个但未用尽全部编号，挑一个外面的 $j$。在这两种情形，整个乘积变号，因此标量部分只能是零。

只剩一种例外：全体编号都出现一次，而且 $k$ 为奇数。这时 $T$ 正是 $S$ 的补集。所有这些配法共有一个因子 $t(B_1\cdots B_k)\prod_i c_i s_i$。要证明其余符号总和为零，可以换成一组记号 $x_i$：仍然交换变号，但规定 $x_i^2=0$。在这套“外代数”记号里，交换相邻的两个回程因子只附加一个偶次因子，因为
$$
(1+x)(1+y)=(1+2xy)(1+y)(1+x).
$$
这些偶次因子可以移到一旁。把回程调成逆序，余下各对 $(1+x_i)(1-x_i)=1$；整个积于是只含偶次项。奇数个不同记号一次全选的系数为零，正好消掉那组例外项。**不是每项为零，而是整组相加为零。**

## 边界与出处

把仍保持先后次序的编号对画成边，符号就由所选顶点间的边数奇偶决定。没有边时答案恒为 1；有一条边就能只留下那条边，得到从 $-1$ 到 $1$ 的全部值。断开的部分独立相乘，但不能把一条边的两个端点分到不同因子中。这个模型只直接解释平方都为 $-1$ 时的概率公式；混合平方符号时，相应的加权和不能一般当作概率平均。标量公式也不决定高次幂的标量：源文三因子结论不能直接搬到四因子。
